# What is Yalah Ntaybo project?
In a context where Morocco's culinary heritage is rich yet sometimes underrepresented on digital platforms, it becomes essential to promote and share these traditional recipes in a modern and accessible way. The main challenge was to design a complete web application using core web technologies, allowing users not only to browse Moroccan recipes but also to actively contribute by publishing their own and interacting with others. That’s why [Assia](https://www.linkedin.com/in/assia-houbbadi-6726b0272/), [Oumaima](https://www.linkedin.com/in/omaima-sabri-129396318/), and [I](https://www.linkedin.com/in/aymen-igri-8b6167304) decided to bring this idea to life. This project, titled Yalah Ntaybo, aims to create a collaborative space dedicated to Moroccan cuisine, where sharing, discovery, and the transmission of culinary knowledge are at the heart of the user experience.
